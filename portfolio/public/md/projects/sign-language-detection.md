# Real-time sign language detection

Custom SSD object detector.

> An end-to-end custom object-detection system that recognizes hand gestures and translates sign language into text in real time for people with hearing impairments.

- Kind: Computer vision
- Period: Apr 2021 to Oct 2021 (completed)
- Affiliation: Independent project

## Problem

Communication barriers for users of sign language in everyday settings.

## Approach

Trained a Single Shot Multibox Detector in TensorFlow on a custom gesture dataset and integrated it with a live camera feed.

## Results

- Accurate real-time detection and translation of multiple gestures.

## Key numbers

- Architecture: SSD

## Stack

TensorFlow, Python, object detection, OpenCV
