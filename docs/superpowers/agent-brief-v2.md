## Hard rules (taste skill, Web Interface Guidelines, her own rules)

- Zero em dashes or en dashes in any string you write, including comments and docs. Use commas, colons, periods or "to".
- Sentence case headings. No hype words. Headlines of two lines or fewer. Body text 16 px or larger, anything readable at 4.5:1 or better; `text-ink-3` only for decoration.
- Three-second test on every section and page: a reader must find the problem, what she did and what changed within one glance. Lead with the outcome line.
- No three equal cards, no bordered white cards, no eyebrow labels on every section, no 01/02/03 numbering, no decorative dots, no scroll cues, no marquees, no infinite sliders, no placeholder or AI-generated imagery. Real assets only: `public/portrait`, `public/projects/<slug>/`, `public/images/certs`, `public/videos/<slug>.{mp4,jpg,webp}`, `public/logos`, `public/people`.
- Motion: transform and opacity only, 240 to 700 ms, `prefers-reduced-motion` turns everything non-essential off (use `useReducedMotion` from `motion/react` or the CSS media query). No `window.addEventListener('scroll')`; use IntersectionObserver, `useScroll`, or the `Reveal` component. Scroll-linked effects must be cheap (no layout thrash).
- Performance budget: no client component above the fold except the hero canvas; everything interactive loads through `next/dynamic` with `ssr: false` inside an intersection-mounted wrapper; images through `next/image` with explicit width and height or `publicImageSize`; videos `preload="none"` with a poster; no new npm dependencies (say so in the report if you believe one is unavoidable).
- Accessibility: one h1 per page, headings in order, labels on icon-only buttons, 44 px targets, visible focus (`focus-visible` ring is global), `aria-current` on nav, dialogs trap focus and close on Escape, popovers close on Escape and outside click, keyboard operable instruments (arrow keys for sliders and scrubbers), `aria-live` for values that change, `scroll-mt-24` on anchored headings.
- Mobile first: every multi-column layout collapses explicitly below 768 px; sideways rows only inside an `overflow-x-auto` container with `scroll-snap-type: x mandatory` and a visible edge; never cause horizontal page scroll. Check 320, 390, 430, 768, 1440 in your head and in the browser.
- Dark only: do not add `[data-theme]` logic; the theme agent removes the toggle.
